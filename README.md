# Speak-Up English Online Academy

Modern enrollment website for Speak-Up English Online Academy, built with Next.js, Tailwind CSS, and an Express/MongoDB backend scaffold.

## Run Locally

```bash
npm install
npm run dev
```

Backend API:

```bash
cp .env.example .env
npm run server
```

## Deployment

- Frontend: Vercel
- Backend: Render or Railway
- Database: MongoDB Atlas

Add Razorpay credentials and email SMTP settings in `.env` before production payments and notifications.
